# Entusiasta Web Application

A web application for managing and participating in online auctions. Users can browse available items, create auctions, place bids, and manage their listings through an interactive web interface.

## Features

* User registration and authentication
* Creation and management of auction listings
* Browsing and searching available auctions
* Real-time bidding functionality
* Bid validation and auction management
* User-specific auction and bidding information
* Responsive and interactive web interface

## Technologies

* **Frontend:** Vue.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Containerization:** Docker
* **API:** RESTful APIs

## Architecture

The application follows a client-server architecture:

* **Vue.js** provides the frontend and user interface.
* **Express.js / Node.js** handles the backend logic and exposes REST APIs.
* **MongoDB** stores users, auctions, bids, and related data.
* **Docker** is used to containerize the application and simplify its deployment.



## Purpose

This project was developed as a university project to gain practical experience in full-stack web development, REST API design and containerized applications.
